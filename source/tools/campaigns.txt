# Single-player campaigns the port ships, read by select_campaigns.py.
#
# One New Game menu entry per line, spelled exactly as the menu shows it (the
# last ";" field of its MetaClass=UnrealShare.SinglePlayer line in a System
# .int file). Every other campaign entry is taken out of the menu, and the
# maps, packages, music, sounds and textures that only those campaigns use are
# not shipped. The stock Unreal Gold files are always shipped.
#
# A line "map NAME" also ships map NAME (and what it needs), for a level that
# a kept campaign reaches only through UnrealScript and not through a map URL.
# A line "package NAME" ships a package that no map needs, such as a player
# model a campaign's readme recommends.
